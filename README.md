# 📑 Applicant Tracking System (ATS)

Welcome to the **Applicant Tracking System (ATS)** — a simple yet powerful web application to help recruiters and hiring managers manage job applications more efficiently.

---

## 🚀 What is this project?

This ATS allows you to:
- Upload and store multiple CVs.
- Analyze CV data automatically.
- Search and filter applicants by various criteria.
- Rank applicants by match score and readiness.
- Manage your applicant pool in one place.

It is built with:
- **Frontend:** React
- **Backend:** Flask (Python)
- **MODEL:** llama 3.1 8B(using ollama)
- **Database:** Local or cloud database (like SQLite or PostgreSQL)
- **Version Control:** Git & GitHub
